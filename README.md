# Tech-tree-emulator

一个单文件运行的科幻风科技树模拟器，打开 HTML 即可编辑科技树、配置资源与事件，并切换到游玩模式进行研究和强化。

## 特性

- **编辑 / 游玩双模式**：游玩模式只保留研究、升级与总览，隐藏全部编辑控件。
- **可自定义科技节点**：图标、等级上限、研究成本、成本货币、升级花费、产出间隔、增益与减益。
- **多货币系统**：内置多种资源，也可自行添加货币（名称、图标、颜色、初始值）。
- **事件系统**：节点可挂载事件触发器（间隔 + 概率），支持独立事件库、事件编辑与事件日志。
- **科技树管理**：多存档切换与删除、清空科技树、导入 / 导出。
- **画布操作**：缩放平移、框选多选整体移动、长按删除、连线吸附与自动整理。
- **总览视图**：一屏查看全部科技，快捷研究或强化。
- **深空科幻界面**：蓝图网格、动态玻璃面板与青蓝高亮，适配手机竖屏。

## 使用

直接打开 [`assets/科技树模拟器.html`](assets/科技树模拟器.html)，无需安装依赖或启动服务。
